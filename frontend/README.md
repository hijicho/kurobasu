# フロントエンド概要

このディレクトリは Kurobasu プロジェクトのフロントエンド実装を含みます。
ここではディレクトリ構成、ローカルでの立ち上げ方法、ビルド手順、主要なファイルや開発時の注意点をまとめます。

## 概要
このフォルダは TypeScript + React を用いたフロントエンドコードを格納しています。
プロジェクトには UI コンポーネント、ページ（`app` / `pages`）、スタイル、アセット、ビルド設定などが含まれます。

※ 実際のスクリプト（`dev` / `build` など）は `package.json` に定義されています。はじめに `package.json` を確認してください。

## ディレクトリ構成（主要）
（リポジトリの一部を抜粋）

- `src/`
	- `app/` - アプリケーションルート・ページ（Next.js の `app` 構成に似た構造）
		- 各ページコンポーネント（例: `login/`, `mypage/`, `course/` など）
		- `*Client.tsx` のようなクライアント専用コンポーネントが混在しています。
	- `components/` - 再利用可能な UI コンポーネント群（UI primitives とページ固有コンポーネント）
		- `ui/` 以下にボタン、入力、モーダル 等の汎用コンポーネントがまとまっています。
	- `pages/` - 従来のページコンポーネント（プロジェクトの移行履歴で両方が存在する可能性があります）
	- `styles/` - グローバル CSS やテーマ用ユーティリティ
	- `assets/` - 画像や静的ファイル

- ルート直下
	- `vite.config.ts` - Vite を使う設定（存在する場合）
	- `package.json` - スクリプトと依存関係
	- `tsconfig.json`, `next.config.js`, `next-env.d.ts` などの設定ファイル

この構造はプロジェクト履歴により Next.js の設定と Vite 設定が混在しているように見える箇所があります。実行時はルートの `package.json` に従ってください。

## 開発（ローカル実行）
基本的な流れは次の通りです。実際のコマンドは `package.json` の `scripts` を確認して合わせてください。

1. 依存関係をインストール

```bash
# ルートが frontend/ の場合
npm install
# または
pnpm install
# または
yarn install
```

2. 開発サーバを起動

```bash
npm run dev
# または package.json に合わせたスクリプトを実行
```

3. ブラウザで表示
開発サーバの出力に従い、通常は http://localhost:5173 や http://localhost:3000 などでアクセスします。

## ビルドと本番プレビュー
本番用ビルドの手順（package.json に沿って実行）

```bash
npm run build
npm run preview # ビルドをローカルで確認する場合
```

ビルドの出力先やプレビューの挙動はプロジェクトのビルド設定（Vite / Next 等）に依存します。

## 主要ファイルの説明
- `src/app/layout.tsx` - アプリケーションの共通レイアウト
- `src/app/page.tsx` - トップページ（ルート）
- `src/components/*` - 再利用可能コンポーネント
- `src/components/ui/*` - デザインシステムのプリミティブ
- `src/styles/globals.css` - グローバルスタイル
- `vite.config.ts` / `next.config.js` - ビルドツールの設定
- `package.json` - スクリプト、依存関係（必ず確認してください）

特にコンポーネント設計では `Client` と名前に付くファイル（例: `TopPageClient.tsx`）がクライアント専用（ブラウザのみ）コンポーネントであることが多いです。

## 開発ルールと注意点
- 既存のコンポーネントは TypeScript で書かれています。型チェックを有効にしてください。
- スタイルはグローバル CSS とコンポーネント単位のスタイルが混在しています。変更時は影響範囲を確認してください。
- `app/` と `pages/` が混在している場合、プロジェクトがどちらのルーティング方式を使っているか（Next.js の場合）を確認してください。
- 依存関係を追加する際は `package.json` を更新し、lockfile（`package-lock.json` / `pnpm-lock.yaml` / `yarn.lock`）をコミットしてください。
